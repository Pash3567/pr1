# Foodieland

Responsive multi-page recipe website recreated from the supplied Figma design.

## Pages

- Home
- Recipes and filtering
- Recipe details
- Blog list and search
- Blog article
- Contact form
- About page

## Features

- Responsive layout for desktop, tablet and mobile
- Hash-based navigation that works on GitHub Pages
- Recipe filters, saved favorites and blog search
- Accessible navigation and forms
- Local design assets with no build step or runtime dependency

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
npx serve .
```

## Deploy

The project is ready for GitHub Pages from the repository root.
